# Formula Byte Next.js Proper Conversion

This project converts the uploaded HTML pages into a Next.js App Router codebase using TSX page components, route-level pages, metadata, and separate CSS files.

## Run

```bash
npm install
npm run dev
```

## Routes

- `/`
- `/about`
- `/contact`
- `/auth`
- `/excel-spreadsheet-generator`
- `/excel-file-generator`
- `/formula-byte-vs-formula-bot`
- `/connectors/google-analytics`

## Structure

```txt
app/
components/pages/
components/runtime/
public/page-styles/
```
